# 预览图片生成功能配置指南

## 功能概述

系统现在支持将每个配色方案的HTML示例自动生成为预览图片，并保存到Vercel Blob存储中。

## ✅ 已完成的启用步骤

### 1. 依赖安装 ✅
已安装完成：
- `playwright` 依赖包
- Chromium 浏览器

### 2. 功能配置 ✅
已完成配置：
- 默认启用预览图片生成功能
- 可通过环境变量 `ENABLE_PREVIEW_GENERATION=false` 禁用

### 3. 代码启用 ✅
已启用的功能：
- ✅ 已启用 `import { chromium } from 'playwright';`
- ✅ 已启用 `generatePreviewImage` 函数中的实际生成代码

### 4. Vercel部署配置 ✅
已创建 `vercel.json` 配置文件：
```json
{
  "functions": {
    "app/api/colors/example/route.ts": {
      "maxDuration": 30
    }
  }
}
```

### 5. 用户界面配置 ✅
- ✅ 当同时存在预览图片和iframe时，默认显示预览图片
- ✅ 用户可以手动切换图片/实时预览模式

## 技术规格

### 截图配置
- **分辨率**: 1200x800px
- **格式**: PNG
- **质量**: 90%
- **截图范围**: 可视区域（非整页）

### 存储配置
- **存储路径**: `ai-colors-previews/{hex}/{theory}-{userId}-{timestamp}.png`
- **访问权限**: 公开
- **内容类型**: image/png

### 数据库字段
新增了以下字段来存储预览图片URL：
- `previewComp` - 互补色预览图片
- `previewAnal` - 类似色预览图片
- `previewTria` - 三角色预览图片
- `previewMono` - 单色预览图片
- `previewSpCo` - 分割互补色预览图片

## API响应变化

### POST /api/colors/example

**之前的响应**:
```json
{
  "url": "https://example.com/html-file.html"
}
```

**现在的响应**:
```json
{
  "url": "https://example.com/html-file.html",
  "previewUrl": "https://example.com/preview-image.png"
}
```

### GET /api/colors/example

schemes数组中的每个对象现在包含 `previewUrl` 字段：
```json
{
  "id": "...",
  "hex": "#132c33",
  "schemes": [
    {
      "theory": "Complementary",
      "colors": ["#132c33", "#331a13"],
      "url": "https://example.com/comp.html",
      "previewUrl": "https://example.com/comp.png"
    }
  ]
}
```

## 性能考虑

### 执行时间
- HTML生成: ~2-5秒
- 图片生成: ~3-8秒
- 总增加时间: ~3-8秒

### 存储成本
- 每张图片约 50-200KB
- 每个用户每个颜色最多5张图片（5种配色方案）

### 优化建议

1. **缓存策略**: 检查HTML内容是否变化，避免重复生成
2. **异步处理**: 将图片生成移到后台队列
3. **压缩优化**: 使用更高的压缩比或WebP格式
4. **按需生成**: 只在用户访问时才生成图片

## 故障排除

### 常见问题

1. **Playwright安装失败**
```bash
# 手动安装浏览器
npx playwright install chromium
```

2. **Vercel部署超时**
- 增加函数超时时间到30秒
- 考虑使用异步处理

3. **图片生成失败**
- 检查HTML是否可访问
- 检查网络连接
- 查看函数日志

### 调试模式

在 `generatePreviewImage` 函数中添加更多日志：

```typescript
console.log('页面加载状态:', await page.evaluate(() => document.readyState));
console.log('页面标题:', await page.title());
```

## 禁用功能

如果需要暂时禁用预览图片生成：

1. 设置环境变量：
```env
ENABLE_PREVIEW_GENERATION=false
```

2. 或者注释掉相关代码

功能被禁用时，系统会正常生成HTML示例，只是不会生成预览图片。
