## 📊 技术规格

### 图片生成
- **技术栈**: Playwright + Chromium
- **分辨率**: 1200x800px
- **格式**: PNG (质量90%)
- **存储**: Vercel Blob

### 存储路径
```
ai-colors-previews/{hex}/{theory}-{userId}-{timestamp}.png
```

### 数据库字段映射
- Complementary → `previewComp`
- Analogous → `previewAnal`
- Triadic → `previewTria`
- Monochromatic → `previewMono`
- Split-Complementary → `previewSpCo`

## 🎯 工作流程

1. **HTML生成** → 上传到Vercel Blob
2. **图片生成** → 使用Playwright截图HTML页面
3. **图片上传** → 保存到Vercel Blob
4. **数据库更新** → 保存HTML和图片URL
5. **前端显示** → 支持图片/实时预览切换
